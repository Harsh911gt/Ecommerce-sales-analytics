# Data Cleaning & Analysis

# 01_data_cleaning_analysis.ipynb

This notebook covers:

- **Data Loading**: Load 9 relational CSV files from Olist dataset
- **Data Cleaning**: Handle missing values, data type conversions
- **Feature Engineering**: Create `delivery_days`, `is_late` columns
- **EDA**: Exploratory data analysis on 100K+ records
- **SQL Queries**: KPI calculations using SQLite
- **Insights**: Delivery impact, revenue trends, payment patterns

# How to Run

1. Open `01_data_cleaning_analysis.ipynb` in Jupyter Notebook
2. Install requirements: pandas, numpy, sqlite3
3. Run cells sequentially from top to bottom
