# Data

# Olist Brazilian E-Commerce Dataset

- Source: Kaggle - Olist Brazilian E-Commerce Public Dataset
- Records: 100K+ orders from 2016-2018
- Files: 9 CSV files (orders, customers, products, payments, reviews, etc.)

# How to Use
1. Download from: https://www.kaggle.com/olistbr/brazilian-ecommerce
2. Extract CSV files to this folder
3. Run the notebook in `/notebooks/` folder
